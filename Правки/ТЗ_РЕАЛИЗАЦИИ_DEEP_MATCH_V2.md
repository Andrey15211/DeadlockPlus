# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Полная реализация концепции Deep Match (V2.0)
> **Проект:** Deadlock Plus (DeadlockForge)  
> **Дата:** 18 октября 2026 г.  
> **Стек:** Vanilla JS (ES Modules), CSS (hud.css / animations.css), HTML5, FastAPI, SQLite  
> **Статус:** Утверждено после архитектурного интервью (/grill-me)

---

## 1. Цель и архитектурные рамки
Реализовать в интерфейсе и связать с бэкендом ключевые фичи глубокого анализа матчей (Deep Match), заложенные в концепцию, но не выведенные в UI:
1. Выбор трёх глубин разбора (`short`, `medium`, `deep`) через Segmented Control перед стартом.
2. Возможность мгновенного переразбора матча (`Reanalyze`) с новой глубиной/моделью в один клик.
3. Полноценная кинематографичная анимация оценки матча в стиле **Devil May Cry 5** (шкала стиля C → B → A → S → S+ с отскоком и свечением).
4. Блок сравнения игрока «с самим собой в прошлом» на выбранном герое (тренд душ, смертей, KDA).
5. Визуализация смертей черепками на интерактивной миникарте (для матчей по Match ID с координатами `death_pos`).
6. Автоматическое подмешивание персонального контекста (топ-3 типичных ошибок игрока из прошлых разборов в SQLite).
7. *In-Game Live Assistant* — временно вынесен за скобки (Out of Scope), приоритет отдан совершенствованию разбора в основном окне.

## 3. Модуль 2: Анимация оценки в стиле Devil May Cry 5 (Style Rank)

### 3.1 Механика анимации
При завершении разбора блок оценки `#dmc-grade-block` запускает эффект Style Rank:
1. **Фаза нарастания стиля (0.0с – 1.2с):**
   - Буквы переключаются снизу вверх с нарастающим звуковым щелчком: `C` → `B` → `A` → `S` (до целевого ранга).
   - Круговая или линейная шкала стиля заполняется динамически (`stroke-dashoffset` от 0 до целевого процента).
2. **Фаза удара / Впечатывания (Impact):**
   - Достигнув итогового ранга, буква замирает, увеличивается до `scale(1.5)` и резко сжимается с упругим отскоком (`cubic-bezier(0.175, 0.885, 0.32, 1.275)`).
   - Вокруг буквы расходится радиальная ударная волна (Shockwave Burst).
   - Если оценка `S` или `S+` — включается золотое пламенное свечение (`box-shadow: 0 0 35px rgba(245, 158, 11, 0.8)`).
3. **Фаза стабилизации:**
   - Буква фиксируется в нормальном размере, под ней появляется титул ранга (`DULL` для C, `BRUTAL` для B, `ANARCHIC` для A, `SAVAGE!` для S, `SMOKIN' SEXY STYLE!!` для S+).

### 3.2 Файлы изменений
- `web/css/animations.css`: keyframes `dmc-rank-sequence`, `dmc-letter-impact`, `dmc-shockwave`.
- `web/js/deep_match.js`: функция `animateDmcGrade(targetGrade)` с пошаговым переключением интервалами `setTimeout/requestAnimationFrame`.

## 5. Модуль 4: Интерактивная карта смертей (Death Breakdown)

### 5.1 Источник данных
- Бэкенд `NormalizedMatch` уже парсит координаты `pos_x`, `pos_y` (от 0.0 до 1.0) из телеметрии API (`death_details.death_pos`).
- В `app.py` при запросе матча по Match ID отдавать в объекте ответа массив смертей пользователя:
  `deaths_geo: [{ t: 340, pos_x: 0.42, pos_y: 0.68, killer: "haze", reason: "Соло выход на мост" }, ...]`

### 5.2 Фронтенд (`web/js/deep_match.js`, `web/index.html`)
- **Если матч разобран по Match ID (координаты есть):**
  - Под кривой душ рендерится компактная тактическая миникарта Deadlock (через существующий ассет карты).
  - На карту наносятся круглые маркеры-черепки с номерами `1`, `2`, `3` по координатам `pos_x / pos_y`.
  - При клике по маркеру или элементу таймлайна: соответствующая точка пульсирует, а справа выводится вердикт: «Смерть #2 (14:20): Убит Хейз. Выход без обзора при живом Мидбоссе у врага».
- **Если матч разобран по скриншоту (координат нет):**
  - Блок карты плавно скрывается, отображается текстовый список ключевых смертей и ошибок из вердикта ИИ.

## 6. Модуль 5: «Тренер меня знает» (Авто-контекст из SQLite)

### 6.1 Логика сбора контекста (`src/deadlockforge/ai/coach.py`)
- Перед формированием системного промпта коуча сервер делает быстрый запрос в SQLite:
  - Выборка последних 5 сохраненных отчетов игрока из `match_reviews`.
  - Агрегация повторяющихся ошибок из полей `key_mistake` и `coach_conclusion`.
  - Формирование строки `auto_player_context`:
    *«Исторический контекст игрока: в 3 из последних 5 игр зафиксированы ранние смерти из-за переагра на 6-8 минутах и задержка с покупкой предметов на снижение исцеления. Отметь, повторяются ли эти паттерны в текущей игре.»*
- Строка передается в `build_coach_prompt(depth, player_context=auto_player_context)`.
- Игроку ничего не нужно вводить вручную: чем больше матчей разобрано, тем персонализированнее и точнее становятся советы.

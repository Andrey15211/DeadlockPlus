# ТЗ v1.6 (ЧАСТЬ 2 — AI ТРЕНЕР): РАЗРАБОТКА, ТЮНИНГ И КАЛИБРОВКА GEMINI 3.8 FLASH

**Скоуп этого чата:** Только разработка системного промпта, базы знаний по игре и тюнинг качества разбора матчей для `gemini-3.8-flash` в `src/deadlockforge/ai/`.  
**ВАЖНО:** Интерфейс программы (`web/`) не трогать (этим параллельно занимается первый чат).

---

## 1. Целевая модель и стек

- **Модель:** `gemini-3.8-flash` через Google Gemini API (`generateContent` / streaming).
- **Библиотека вызовов:** Уже реализованный чистый клиент `GeminiClient` в `src/deadlockforge/ai/client.py` (stdlib `urllib`, без сторонних SDK).
- **Контракт ответа:** Строгий неизменяемый JSON по Pydantic-схеме `CoachReport` из `src/deadlockforge/models.py`:
  - `performance_grade`: `"S+" | "S" | "A" | "B" | "C"`
  - `key_mistake`: `time`, `location`, `event`, `why_fatal`, `correct_play`
  - `coach_conclusion`: список из 3–5 содержательных пунктов
  - `benchmarks`: `souls_at_10`, `lane_efficiency`, `teamfight_participation`
  - `item_corrections`: список предметов, которые стоило купить, с обоснованием

## 2. Задачи к выполнению

### 1. Формирование базы знаний Deadlock (`deadlock_knowledge.py` / `prompt_pack`)
- Собрать компактную, структурированную базу тактических знаний Deadlock для инъекции в системный промпт:
  - **Тайминги карты The Cursed Apple:** 0:00 (выход 2-2-2), 3:00 (первые лесные кемпы), 10:00 (Soul Urn + Flex слоты), 12:00/15:00 (Midboss фазы), 18:00 (Босс карты).
  - **Критические ошибки позиционирования:** Смерть в соло на чужой половине после 15:00, смерть без выкупа (Buyback) после 25:00, игнорирование доставки Урны, драка в меньшинстве при отставании по душам.
  - **Ключевые контр-предметы:**
    - Против хила (Kelvin, Abrams, Infernus, Ivy) -> Клинок-запретитель (`Healbane`) / Токсичные пули (`Toxic Bullets`).
    - Против пулевого DPS (Haze, Wraith) -> Металлическая кожа (`Metal Skin`) / Обратный огонь (`Return Fire`).
    - Против кастеров/ультов (Seven, McGinnis) -> Нокдаун (`Knockdown`) / Проклятие (`Curse`).
    - Против плотного фронтлайна -> Колосс (`Colossus`) / Снижение пулевого сопр. (`Bullet Resist Shredder`).

### 2. Структурирование системного промпта (`COACH_SYSTEM_PROMPT` в `coach.py`)
- Запретить односложные шаблонные отписки («1 раз умер, главная ошибка»).
- Промпт должен требовать:
  1. **Тактический анализ ключевого момента:** Назвать точный тайминг (`MM:SS`), точку карты и механическую причину слива файта (например: «Выход на линию без вижена при живом Midboss у врага»).

# ПРОМПТ ДЛЯ РЕАЛИЗАЦИИ ПРЕМИАЛЬНЫХ АНИМАЦИЙ И ИНТЕРАКТИВА (DEADLOCKFORGE)

> **Контекст проекта:** Desktop-приложение `DeadlockForge` на базе `pywebview` (Edge WebView2) + Vanilla JS + CSS (`web/css/hud.css`, `web/css/styles.css`).
> **Стилистика:** Оккультный арт-деко / стимпанк (Occult Art-Deco, Valve Deadlock, янтарный `#E5A93C`, фиолетовый `#8B5CF6`, изумрудный `#10B981`, золотой `#ffed79`, глубокий сланец `#070A0F`).

---

## 🎯 ТВОЯ ЗАДАЧА
Модернизировать интерфейс `web/`, внедрив сочные, кинематографичные 60 FPS микро-интеракции, физические переходы и живые визуальные эффекты в стиле современных AAA-клиентов (Dota Plus, League Client, Steam Deck UI), не жертвуя производительностью WebView.

---

## ⚙️ АРХИТЕКТУРНЫЕ ПРАВИЛА И ОГРАНИЧЕНИЯ (WEBVIEW 60 FPS)

1. **Только GPU-композитинг (No Layout Thrashing):**
   - Анимировать **строго** свойства `transform` (используя 3D: `translate3d`, `scale3d`, `rotate3d`) и `opacity`.
   - **Категорически запрещено** анимировать `top`, `left`, `right`, `bottom`, `width`, `height`, `margin`, `padding` — это вызывает перекомпоновку DOM и лаги в WebView.
   - Свойство `will-change: transform, opacity;` вешать только на анимируемые элементы в момент активности/ховера и снимать после, чтобы не забивать видеопамять WebView.
   - Полный запрет на `transition: all`. Все анимируемые свойства указывать явно.

2. **Математика кривых (Cubic-Bezier вместо стандартного ease):**
   Зафиксировать в `:root` и использовать единую систему физики:
   ```css
   --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);       /* Резкий старт, плавное торможение для UI */
   --ease-smooth:   cubic-bezier(0.23, 1, 0.32, 1);       /* Интеракции, меню, карточки */
   --ease-spring:   cubic-bezier(0.34, 1.56, 0.64, 1);     /* Пружинный овершут (штампы, бейджи) */
   --ease-bounce:   cubic-bezier(0.68, -0.6, 0.32, 1.6);  /* Экипировка, сокеты */
   ```

3. **Тайминги и физика:**
   - Тактильный отклик кнопок/кликов: `90ms – 140ms`
   - Тултипы, поповеры, дропдауны: `150ms – 200ms`
   - Карточки, списки, вкладки: `200ms – 280ms`
   - Модальные окна, штампы рангов: `300ms – 380ms`
   - Элементы никогда не появляются из `scale(0)`: только из `scale(0.95)` или `scale(0.96)` с плавным нарастанием непрозрачности.

## 🎨 СПИСОК КОНКРЕТНЫХ ИНТЕРАКТИВНЫХ АНИМАЦИЙ

### 1. Карточки героев, билдов и предметов (3D Tilt & Magnetic Glow)
- **При наведении (`:hover`):**
  - Подъём карточки с перспективой: `transform: perspective(800px) translateY(-4px) scale3d(1.02, 1.02, 1);`
  - Мягкая тень с акцентным свечением цвета категории (Оружие = янтарь, Живучесть = изумруд, Дух = фиолетовый).
  - Световой блик (sheen effect): псевдоэлемент `::after` с полупрозрачным градиентом пробегает под углом 45° поперек карточки за `400ms --ease-out-expo`.
- **При нажатии (`:active`):**
  - Мгновенная компрессия: `transform: perspective(800px) translateY(-1px) scale3d(0.98, 0.98, 1);`

### 2. Переключение вкладок (Staggered Cascade Fade-Up)
- При смене экрана/таба контейнер плавно проявляется, а карточки и блоки внутри появляются каскадом (stagger) со смещением `translateY(12px) -> translateY(0)` и возрастающей задержкой:
  `animation: cardFadeUp 0.24s var(--ease-out-expo) backwards;`
  `animation-delay: calc(var(--index, 0) * 35ms);`
- Это убирает ощущение «статичной веб-страницы» и создает ощущение нативного игрового лаунчера.

### 3. Билд-Лаб: Сокеты и Экипировка (Socket Equip & Upgrade FX)
- **Слоты предметов:** легкое оккультное дыхание границы пустого слота (`box-shadow` пульсация с низкой частотой 3s).
- **При клике/установке предмета в слот:**
  - Яркая кольцевая вспышка границы слота (`keyframes slotFlash`: белое свечение переходит в цвет категории предмета).
  - Микро-толчок иконки: `scale(1.2) -> scale(1.0)` с кривой `--ease-spring`.
  - Эффект прокачки Т1 -> Т2: золотая искра/обводка по периметру слота.

### 4. Deep Match: Анализ и Штамп Ранга (Rank Stamp & Souls Curve)
- **Индикатор анализа нейросети:**
  - Живой радар-сканер вокруг аватара и логов: градиентная бегущая полоса по рамке (conic-gradient или shimmering line).
- **График душ (Souls Curve SVG):**
  - Плавная отрисовка линии слева направо с анимацией `stroke-dasharray` и `stroke-dashoffset` за `1.0s --ease-smooth`.
  - Точки пиков и смертей всплывают по очереди с микро-пульсацией.
- **Оценка матча (S+, S, A, B, C):**
  - Эффект физического удара штампа: появление из `scale(2.5)` с размытием `filter: blur(4px)` и падением в `scale(1)` с пружинным отскоком `--ease-spring` (320ms).
  - В момент «удара» штампа: расходящаяся ударная волна свечения вокруг плашки ранга (`box-shadow: 0 0 40px var(--gold-color)` затухает за 400ms).

### 5. Тултипы и Поповеры предметов/способностей
- Всплывают без задержек по координатам курсора.
- Появление: `transform: translateY(6px) scale(0.97)` → `transform: translateY(0) scale(1)` с `opacity: 0 -> 1` за `150ms`.
- Градиентная рамка с легким неоновым свечением, соответствующим типу урона/улучшения.
- Бейджи «Пассивное» и «Активное» с легким градиентным мерцанием при первом открытии.

### 6. Тосты и уведомления (Physical Push-Up)
- Вылет снизу по центру: `translateY(100%) scale(0.9) -> translateY(0) scale(1)` за `220ms --ease-spring`.
- Индикатор таймера закрытия (прогресс-бар снизу тоста, угасающий в реальном времени).

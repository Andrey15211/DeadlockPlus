## Общие принципы

- Ростер 44 героев не трогать. Скиллы/названия без официального русского
  локала — НЕ переводить (оставить английским), кривые автопереводы
  вычистить.
- Все UI-тексты на русском; программные идентификаторы/JSON — английский.
- Каждый трек: `python -m pytest -q` зелёный + ручная проверка экрана.
- Диагностика UI: запуск с env `DEADLOCK_DEBUG=1` (DevTools включаются) —
  стандартный шаг отладки вместо F12.

## Трек D — Backend / Data (субагент «backend»)
Скоуп: `src/deadlockforge/**`, `scripts/**`, `data/items.json`.

### D1. Иконки: закрыть 27+54 дыр (замечание 1, диагностировано)
Проблема: 187/214 иконок совпадают по слагу, 27 предметов не имеют слаг-файла
(числовые имена из API), у 54 нет прямого маппинга slug→icon в
`/v1/assets/items`.
- Скрипт `scripts/fix_item_icons.py`: для каждого предмета `data/items.json`
  найти иконку через `/v1/assets/items` (по `class_name`, префиксы
  `upgrade_`/`ability_`, синонимы), скачать как `web/assets/items/{slug}.webp`.
  Несовпадения — в ручной маппинг `data/icon_overrides.json`
  (slug → числовой id или прямой URL).
- 27 базовых T1-предметов без shop-иконок в API: поискать ability-иконки;
  если нет — сгенерировать заглушки-миниатюры (буква на фирменном фоне,
  `scripts/make_icon.py` уже есть как основа).
- Акцептанс: 214/214 предметов имеют иконку (реальную или сгенерированную
  заглушку в едином стиле), `qa_lab_icons.png`-аналог после прогона — ни
  одной буквенной заглушки кроме заведомо сгенерированных.

### D2. Автоподтягивание Steam-профиля (замечания 7, 8)
- Ник и аватарка из Steam: `steam_profile.py` + Steam Web API
  `GET ISteamUser/GetPlayerSummaries/v2` (бесплатный ключ не нужен для
  одного профиля? — НЕТ, нужен ключ; альтернатива без ключа:
  `api.deadlock-api.com/v1/players/{account_id}/steam` если отдаёт
  persona/аватар — проверить сначала его). Аватар кэшировать в
  `web/assets/avatars/{account_id}.jpg`, TTL 24ч.
- Ранг: `GET /v1/players/{account_id}/rank` → `rank`, `subrank`, `badge`.
  Автозаполнение `rank_tier`/`rank_subrank` профиля.
- **Обязательное требование:** при `rank:0` и `last_match:null` —
  фронтенду отдаётся статус `rank_hidden: true` → красная плашка
  «Ранг скрыт. Включите Public match data в Deadlock: Настройки → Игра →
  Общие → "Сделать данные матчей общедоступными"». Программа полностью
  работоспособна, плашка висит до включения.
- MMR: НЕ автоматизировать (эндпоинты deprecated, будут удалены) —
  ручное поле остаётся.
- Акцептанс: профиль подтягивает ник+аватар+ранг одной кнопкой/авто;
  при скрытом ранге — плачка с инструкцией; MMR поле ручное.

### D3. Rate-limit и кэш матч-данных (замечания 9, 10)
- Парсинг 429-ответов deadlock-api: выделять `next_request_in`,
  показывать «Лимит API (3 запроса/час). Повторите через N мин.» —
  и на бэке (HTTPException detail), и форматированно на фронте.
- Кэш сырья матчей: скачанный `/v1/matches/{id}/metadata` целиком
  сохраняется в SQLite (таблица `match_raw`), повторные разборы того же
  матча не тратят квоту. TTL «навсегда» (метаданные матча неизменны).
- Список последних матчей: не дёргать автоматически при каждом открытии
  экрана — только кнопка «Обновить»/первый вход с истекшим кэшем (TTL
  поднять с 10 мин до 60 мин).
- Опционально (env `DEADLOCK_API_KEY`): Patreon-токен deadlock-api в
  заголовке, если пользователь подписан — без изменений логики.
- Акцептанс: повторный «Разобрать» на разобранном матче не делает
  исходящий запрос к deadlock-api (проверить логом/моком в тестах);
  429-ответ в UI — человеческая строка, не JSON.

### D4. Разбор по кнопке + реальный progress (замечание 2)
- «Разобрать» = явный запрос: бэкенд дёргает LLM только по клику (сейчас,
  судя по QA, анализ уже вызывается по клику — убедиться, что никакой
  предгенерации/эвристики не подсовывается до ответа нейронки).
- **Progress bar с реальным прогрессом**: перейти на streaming
  (`stream: true` у deepseek/openai-совместимых; `streamGenerateContent` у
  gemini; у anthropic — `stream: true`). Прогресс = доля полученных
  chunk'ов от оценённого объёма (по `usage` финального chunk'а прошлых
  запросов — хранить скользящую оценку; первая загрузка —
  неопределённый индикатор + счётчик секунд). WebSocket или SSE с бэка
  (`/api/match/analyze` → SSE-эндпоинт `/api/match/analyze/stream`).
- Промпт coach.py: убрать «1 раз умер, главная ошибка»-минимализм —
  структура отчёта: что делал хорошо / ключевые ошибки с таймингами /
  паттерны (позиционирование, экономика, тайминги объектов) / что делать
  иначе / 3 конкретных упражнения. (Пользователь сказал «потом
  проработаем» — заложить каркас, финальную формулировку согласуем.)
- Акцептанс: клик → индикатор с честным прогрессом → отчёт полного
  формата; без ключа — внятная ошибка, без стектрейса.

## Трек F — Frontend / UI (субагент «frontend»)
Скопп: `web/js/**`, `web/index.html`. CSS только по согласованию с V.

### F1. Счётчик слотов (замечание 5)
- Убрать «(16 слотов, SQLite)» из заголовка. Вместо — интерактивный
  бейдж `0/16` рядом с «Сохранённые билды», обновляется при каждом
  equip/unequip/reset/load/import.
- Акцептанс: бейдж живой на всех путях изменения слотов.

### F2. Подпись матчей и обработка ошибок (замечания 9)
- Список «Последние матчи»: подпись «героем X» сбивает (пользователь
  принял свои матчи за чужие). Переделать: строка = [W/L] KDA · герой ·
  дата, W — зелёный, L — красный, герой — нейтрально.
- 429/сетевые ошибки: показать в тосте/инлайн-плашке
  «Лимит API исчерпан, повторите через ~N мин» — парсинг на бэке (D3),
  фронт только показывает `detail`.
- Акцептанс: на скрине типа `ui_deep_match_429.png` — человеческий
  текст.

### F3. Red Flags и переводы (замечания 3, 4)
- Убрать английские дубли названий из карточек (оставить только если
  русского локала нет — правило выше).
- Данные: `data/items.json` содержит кривые `name`-поля? Проверить
  source артефактов «Unyleilding»/«Fortress Grans» — они приходят из
  `name_en` дублирующихся в UI или из counter_rules.json. Чистить на
  стороне данных (D-трек взаимодействие), не на рендере.
- Контраст карточек: severity-цвета (critical/warning/info) не должны
  совпадать с фоном карточки; текст всегда ≥2 ступени яркости от фона.
- Акцептанс: экран драфта без англ. дублей (кроме безлокальных),
  без повторяющихся «протие spirit_caster», текст читаем.

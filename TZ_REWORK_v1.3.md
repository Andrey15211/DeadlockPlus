## Остаток работ

### Трек A2' — Backend / Data

**A2.1. Recent-matches в Deep Match (недоделка A1).**
Эндпоинт `/api/profile/recent-matches` есть, но UI Deep Match его не
использует — `deep_match.js` про него не знает. Задача: блок «Последние
матчи» в Deep Match (список из 5–10: герой, результат W/L, KDA, дата, кнопка
«Разобрать»), клик подставляет match_id в поле анализа. Кэш/оффлайн уже
решены на бэке.
Акцептанс: при заполненном профиле список появляется без ручного ввода
ID; клик «Разобрать» запускает `/api/match/analyze` с этим match_id; при
отсутствии сети — сообщение, экран не ломается.

### Трек C' — Visual / Design

**C1.1. Иконка в сборках (недоделка C1).**
Ни `DeadlockForge.spec`, ни `DeadlockForge_Portable.spec` не содержат
`icon=` — PyInstaller всё ещё поставит дефолтную иконку. Текущий
`dist/DeadlockForge.exe` (16:52) собран до всех правок и устарел.
Задача: в обоих spec добавить `icon='web/assets/icons/deadlockforge.ico'`
в `EXE(...)`.
Акцептанс: `Select-String icon` в обоих spec непустой.

### Трек D — Packaging / QA (главный остаток)

**D1. Финальная сборка и smoke-чеклист.**
1. Пересобрать оба spec с иконкой (C1.1); проверить, что `web/assets/`
   (items/ 711 шт., map/, icons/) и `data/` в бандле.
2. Smoke-чеклист собранного exe (каждый пункт отметить):
   - [ ] нет окна DevTools (A5);
   - [ ] иконка окна и файла оранжевая (C1.1);
   - [ ] Билд-лаб показывает иконки предметов (B1);
   - [ ] Walker-маркеры внутри игровой зоны на минимапе (B2);
   - [ ] тир-лист без «Меты от тренера», ростер полный, дата меты видна (B3/A2);
   - [ ] «Найти мой профиль» заполняет Steam ID/Account ID сам (A1);
   - [ ] AI-блока настроек нет; при отсутствии ключа — карточка «AI отключён» (B4/A3);
   - [ ] экрана ассетов в навигации нет (A4);
   - [ ] вёрстка драфт-экрана: контр-пики без пустого квадранта, тексты не
     обрезаны на 1440x900 и 1200x768 (B5);
   - [ ] DevTools-консоль чистая (нет 404 favicon).
3. `pytest -q` зелёный; при изменении API-контрактов — обновить
   `tests/test_api.py`, `test_qa_spec.py`.
Акцептанс: чеклист целиком ✓ на свежем `dist/DeadlockForge.exe`; отчёт по
чеклисту сохранён в `QA_REPORT.md` (какой пункт кем/чем проверен).

**D2. Валидация координат карты (закрытие B2).**
Координаты маркеров в map.json проставлены, но их соответствие реальной
минимапе не подтверждено скриншотом. Задача: открыть экран «Карта»,
сделать скрин, убедиться что все 14 маркеров в игровой зоне (особенно

из реального матча ложатся консистентно. При расхождении — поправить
координаты в map.json (править ТОЛЬКО map.json, не js).
Акцептанс: скрин карты с маркерами внутри зоны приложен к QA_REPORT.md.

для финального ревью изменений — `code-review`. Разгон правок — обычные
субагенты, `workflow` не нужен (задач мало и они разнородные).
